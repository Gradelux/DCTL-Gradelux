## How it works
- Manual WB uses `deviceWhiteBalanceGains(for:)` → clamp every channel to `1.0…maxWhiteBalanceGain` → `setWhiteBalanceModeLocked(with:)`.
- Displayed Kelvin/tint come from `temperatureAndTintValues(for:)` on the clamped gains (what the hardware really uses).
- Kelvin slider range is measured on the device at startup: the span around 5000 K whose gains need no clamping.
- Auto → Manual locks the exact gains Auto was using (no color shift). Moving one slider keeps the other value from Auto.
- Tint direction labels (M/G) are measured from the device's own gain conversion.
- WB is re-applied after resolution/frame-rate changes; blocked during recording.

## Test plan
1. Bar ends with `A WB 5xxxK`; it changes when pointing at daylight vs. indoor light.
2. WB panel → turn AUTO WB off: the image color must not change; "A" disappears.
3. Kelvin slider: lower = bluer image, higher = warmer image. Bar value follows (rounded to 50 K).
4. Tint slider toward G = greener, toward M = more magenta.
5. Change resolution / FPS: WB value stays.
6. AUTO WB on: camera adapts again.
7. Record in manual WB → color in Photos matches preview.
8. Regression: ISO, shutter, 4K, FPS, audio, "Saved · …", Photos.
