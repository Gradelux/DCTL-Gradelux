# DCTL-Gradelux
CineCore is a DaVinci Resolve DCTL grading and film-look system currently in development.

## Gradelux iOS app

`Gradelux/` contains the Swift sources for the Gradelux iPhone camera app (Milestone 1: rear-camera preview, video + audio recording, save to Photos).
See [docs/Milestone1-Setup.md](docs/Milestone1-Setup.md) for Xcode setup and testing steps.
